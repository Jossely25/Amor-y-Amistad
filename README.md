# Love & Friendship Web ❤️🌸

Sitio web interactivo desarrollado para celebrar el Día del Amor y la Amistad. La página ofrece una experiencia visual con animaciones, música de fondo e ilustraciones, brindando una presentación creativa y atractiva para compartir mensajes especiales.

## Características

- Página de bienvenida interactiva.
- Animaciones con JavaScript.
- Diseño responsivo.
- Reproducción de música de fondo.
- Ilustraciones y elementos gráficos personalizados.
- Navegación sencilla y ligera.
- Compatible con los principales navegadores web.

---

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Pantalla principal con diseño interactivo.
- Transiciones y animaciones dinámicas.
- Página complementaria con una ilustración floral.
- Música ambiental para mejorar la experiencia del usuario.
- Diseño adaptable a diferentes tamaños de pantalla.

## Requisitos

- Navegador web moderno (Google Chrome, Microsoft Edge, Mozilla Firefox, etc.).

## Instalación

### Clonar el repositorio

```bash
git clone https://github.com/USUARIO/love-and-friendship-web.git
```

### Ejecutar el proyecto

Abrir el archivo:

```text
index.html
```

También puede ejecutarse utilizando un servidor local como **Live Server** en Visual Studio Code para una mejor experiencia durante el desarrollo.

---

## Organización del proyecto

El proyecto está organizado en carpetas independientes para facilitar el mantenimiento:

| Carpeta | Descripción |
|---------|-------------|
| `css/` | Hojas de estilo de la aplicación. |
| `js/` | Scripts encargados de la lógica y las animaciones. |
| `img/` | Recursos gráficos utilizados por el sitio. |
| `sound/` | Archivos de audio utilizados como música de fondo. |
| `html/` | Páginas complementarias del proyecto. |
